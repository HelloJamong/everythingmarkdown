## 이번 단계에서 고친 것

- **OOXML 압축 폭탄 제한**(A08): `service.py`에서 압축 해제 합계와 항목 수를 검사. 이전에는 구조만 확인했다.
- **재시작 복구 보강**(A25): 결과 게시 직후·DB 기록 전에 중단된 작업의 결과 파일과, 파일 저장 후 DB 기록 전에 중단된 고아 폴더를 시작 시 제거. 이전에는 남아 있었다.
- **라이선스 고지**: 이미지 기준 55개 런타임 의존성 목록을 다시 만들고, wheel에 원문이 없는 4개 원문을 `licenses/`에 보충해 이미지에 포함.
